# 장바구니 이탈 리마인드 (Cart Abandonment Reminder)

> 우선순위: **P2(신규)** — [wishlist-price-alert.md](./wishlist-price-alert.md) §0 브레인스토밍 #4
> 작성일: 2026-07-05 / 작성자: 프로덕트 기획(planner)
> 상태: ✅ 구현 완료(2026-07-05, **알림 전용** — 쿠폰 없음)
> 관련 도메인: `cart`(이탈 판정·리마인드), `notification`(기존 알림함 재사용)

## 1. 배경 / 문제 정의

장바구니에 담아두고 결제하지 않고 이탈하는 고객이 많다. 이들은 구매 의사가 이미 뚜렷해 **회수 가치가
가장 높은 집단**이다. 담아둔 채 잊은 고객에게 "장바구니에 상품이 남아 있어요"를 상기시켜 결제로 되돌린다.

## 2. 목표 및 성공지표
- 목표: N시간 이상 미결제로 방치된 장바구니 보유 고객에게 리마인드를 보내 결제 복귀를 유도.
- 성공지표(제안): 리마인드 발송 → 24~72h 내 결제 전환율, 카트 회수율, 리마인드 클릭률.

## 3. 핵심 유저 스토리 & 수용기준(AC)

**US-1. 방치된 장바구니 보유 회원은 리마인드 알림을 받는다.**
- AC1: 마지막 활동 후 임계 시간(기본 24h) 경과 + **비어있지 않은** 장바구니를 가진 회원에게 인앱
  알림(`NotificationType.CART_REMINDER`)이 1회 발송된다.
- AC2: 동일 장바구니에 대해 **중복 발송하지 않는다**(직전 리마인드 이후 새 활동이 없으면 재발송 안 함).
- AC3: 회원 전용. 게스트(localStorage) 장바구니는 대상 외.
- AC4: 알림 클릭 시 장바구니로 이동한다(`linkUrl`).

**US-2. 관리자는 리마인드 배치를 운영한다.**
- AC5: 관리자는 리마인드 발송 배치를 수동 트리거할 수 있다(스케줄러는 기본 비활성).

## 4. 정책/규칙 (확정)

- **MVP는 리마인드 알림만. 자동 쿠폰 발급 없음** (핵심 결정) — "일부러 방치해 쿠폰 받기" 어뷰징을
  원천 차단. 쿠폰 넛지는 어뷰징 정책 확정 후 별도 단계로.
- **이탈 판정**: `Cart.lastActivityAt`이 `now - inactivityHours`(기본 24h)보다 오래되고, 항목이 1개
  이상인 장바구니. `cart-reminder.inactivityHours` 설정으로 조정.
- **dedup**: `lastReminderAt IS NULL OR lastReminderAt < lastActivityAt`인 카트만 대상 → 리마인드
  이후 새 활동이 있어야 다시 발송. 발송 시 `lastReminderAt` 갱신.
- **활동 시각 갱신**: 담기/수량변경/삭제/병합 시 `Cart.touch()`로 `lastActivityAt` 갱신(자식 컬렉션
  변경이 부모 `updatedAt`을 안 건드리는 문제 때문에 명시 컬럼 사용).
- **실패 격리**: 건별 발송 실패가 배치 전체를 중단시키지 않는다.

## 5. 데이터 모델 / API (구현 결과)

```
Cart 확장: lastActivityAt(NOT NULL, 기존 행은 updated_at 백필), lastReminderAt(nullable)
NotificationType 확장: CART_REMINDER 추가(스키마 변경 없음)
```
마이그레이션: **V25__cart_reminder.sql** (`carts` 컬럼 2개 추가).

| 메서드 | 경로 | 설명 | 인증 |
|---|---|---|---|
| POST | `/api/admin/cart-reminders/run` | 리마인드 발송 배치(수동 트리거) | 관리자 |
| GET | `/api/me/notifications?type=CART_REMINDER` | 기존 알림함 재사용(고객용 신규 화면 없음) | 회원 |

## 6. 프론트 화면
- 고객용 신규 화면 없음 — 기존 알림함에 타입별 아이콘으로 노출, 클릭 시 `/cart` 이동.
- 관리자: 운영용 수동 발송 버튼(로열티 등급 화면에 함께 배치).

## 7. 범위 (In / Out of scope)
**In**: 이탈 판정 배치·리마인드 알림 1회·dedup·관리자 수동 트리거.
**Out**: 자동 쿠폰 넛지, 이메일/푸시 발송, 발송 빈도 고도화(다이제스트), 게스트 카트, A/B 문구 실험.

## 8. 오픈 이슈
1. 이탈 임계 시간(기본 24h)과 스케줄러 주기·활성화 시점은 운영 데이터 확인 후 조정.
2. 쿠폰 넛지 확장 여부 — 행동 기반 자동 인센티브 어뷰징 정책(공통 오픈 이슈) 확정이 선행.
3. `CART_REMINDER` 알림 클릭 이동 경로(`linkUrl`)를 백엔드가 `/cart`로 채우는지 확인 필요.
