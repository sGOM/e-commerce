# 추가 구현 로드맵 (Backlog)

마켓플레이스 MVP(백엔드 + 고객 스토어프론트 + 상품 검색/인기 상품)까지 완료된 상태에서,
이후 구현할 만한 기능을 테마별로 정리한다. 각 항목은 **우선순위 / 작업량 / 선행조건**을 함께 표기한다.

- 우선순위: 🔴 높음 · 🟡 중간 · 🟢 낮음
- 작업량: S(1일 이내) · M(2~3일) · L(1주 내외)

> 현재 스택: Kotlin · Spring Boot 3.5 · PostgreSQL/Flyway · 세션 인증/RBAC · React+Vite+TS 스토어프론트

## 추천 진행 순서

실제 운영 가능한 상점을 목표로 한 최소 경로:

1. **결제 완성** — 1.1 게스트 결제 → 1.2 Toss 위젯 → 1.4 주문 취소/환불
2. **상품 완성도** — 2.1 이미지 업로드 → 2.4 리뷰/평점
3. **배송 운영** — 4.3 배송 처리/송장 → 5.2 정산 지급
4. **회원 필수** — 3.1 비밀번호 → 3.2 배송지 주소록
5. **알림 + 품질** — 6.1 이메일 → 7.1 프론트 테스트 → 7.5 CI/CD

> 이 순서는 "주문→결제→배송→정산"의 실거래 라이프사이클을 먼저 닫고,
> 그 위에 신뢰(리뷰)·재구매(회원/알림)·운영 안정성(테스트/CI) 순으로 쌓는 흐름이다.
